## 1. ΚΑΝΟΝΕΣ ΔΟΜΗΣ ΚΕΦΑΛΑΙΟΥ
- **Παιδαγωγική Ροή Κεφαλαίου:**
  1. `00-stoxoi.js`: Σαφείς επιδιωκόμενοι διδακτικοί στόχοι (`slug: "stoxoi"`, `num: "N.0"`).
  2. `01-<slug>.js`, `02-<slug>.js` κ.ο.κ.: Λογικά διατεταγμένες υποενότητες (προχώρησε από το οικείο προς το νέο).
  3. Προτελευταίο section: Σύντομη περίληψη / ανακεφαλαίωση & Συγκεντρωτικό Τυπολόγιο (`slug: "perilipsi"`).
  4. Τελευταίο section: **Σημεία Προσοχής & Σύνοψη SOS** (`slug: "sfalmata-kai-dieykriniseis"`).
     - **ΚΑΝΟΝΑΣ ΑΠΟΚΛΕΙΣΜΟΥ ΙΕΠ:** Απαγορεύεται ρητά οποιαδήποτε αναφορά στη λέξη ή ταυτότητα «ΙΕΠ».
     - **ΑΠΑΓΟΡΕΥΣΗ ΑΒΑΣΙΜΩΝ ΠΑΡΑΤΗΡΗΣΕΩΝ:** Απαγορεύονται αυστηρά οι αβάσιμες παρατηρήσεις, η επινόηση δήθεν «σφαλμάτων του βιβλίου» και οι υπεροπτικές κριτικές. Το υλικό παραμένει πιστό στο σχολικό εγχειρίδιο και εστιάζει αποκλειστικά σε ουσιαστικές οδηγίες επίλυσης, σημεία προσοχής και ασφαλή προετοιμασία για τις εξετάσεις.

- **Παιδαγωγικό Μοντέλο 4 Βημάτων ανά Υποενότητα:**
  1. *Διαίσθηση & Πρακτική Σύνδεση:* Απλό παράδειγμα από την καθημερινότητα ή το συνεργείο/μηχανή.
  2. *Βασική Θεωρία, Ορισμοί & Τύποι:* Καθαρά bullets, έντονα γράμματα, display LaTeX `\\[ ... \\]`, επεξήγηση συμβόλων και μονάδες SI.
  3. *Λυμένο Υπόδειγμα:* Βήμα-βήμα υπολογισμός (Δεδομένα -> Ζητούμενα -> Τύπος -> Αντικατάσταση -> Αποτέλεσμα).
  4. *Tip Τράπεζας Θεμάτων / SOS:* Σημεία συχνών λαθών και μετατροπές μονάδων.

- **ΠΑΙΔΑΓΩΓΙΚΗ ΣΤΟΙΧΙΣΗ ΙΣΩΣΕΩΝ («ΑΠΟ ΚΑΤΩ ΤΟ ΙΣΟΝ»):**
  - Σε κάθε μαθηματικό τύπο, υπολογισμό, αντικατάσταση ή επίλυση εξίσωσης με διαδοχικά βήματα, το σύμβολο της ισότητας (`=`) πηγαίνει **ΠΑΝΤΑ από κάτω στη νέα γραμμή** με κατακόρυφη στοίχιση:
    ```latex
    \begin{aligned}
    A &= B \\
    &= C \\
    &= D
    \end{aligned}
    ```
  - **Ποτέ δεν γράφουμε μακροσκελή οριζόντια αλυσίδα ισοτήτων** ($A = B = C = D$). Η κατακόρυφη στοίχιση εξασφαλίζει άριστη ανάγνωση και αποτρέπει οποιαδήποτε έξοδο από το πλαίσιο της σελίδας.

- **ΠΛΗΡΗΣ ΣΥΜΠΕΡΙΛΗΨΗ ΠΙΝΑΚΩΝ (ΥΠΟΔΙΑΙΡΕΣΕΙΣ & ΠΟΛΛΑΠΛΑΣΙΑ):**
  - Όλοι οι πίνακες αναφοράς του βιβλίου συμπεριλαμβάνονται πλήρως.
  - Ειδικά σε εισαγωγικές ενότητες ή ενότητες μονάδων, **απαγορεύεται η παράλειψη του πίνακα υποδιαιρέσεων και πολλαπλασίων (προθέματα SI: Tera, Giga, Mega, Kilo, deci, centi, milli, micro, nano, pico με τις δυνάμεις του 10)**.

- **ΣΑΦΗΣ ΔΙΑΚΡΙΣΗ ΕΙΣΑΓΩΓΗΣ ΚΑΙ ΚΕΦΑΛΑΙΟΥ 1:**
  - Η «Εισαγωγή» του βιβλίου (Μονάδες, Συστήματα SI, Τριγωνομετρία) είναι αυτόνομο εισαγωγικό μέρος και **ΔΕΝ συγχέεται με το Κεφάλαιο 1** (το οποίο ξεκινά από τις Δυνάμεις).

- **Κατάτμηση:** Κάθε υποενότητα να έχει έναν ξεκάθαρο σκοπό. Χώρισε το υλικό σε μικρές, ευανάγνωστες ενότητες· απόφυγε μεγάλες, πυκνές παραγράφους και επαναλήψεις.
- **Αρίθμηση & Ονοματοδοσία:** Διατήρησε την αρίθμηση του κεφαλαίου και τη μορφή των `num` (π.χ. `1.1`, `1.2`). Κράτησε μοναδικά `slug`, σαφείς τίτλους και περιγραφικά ονόματα αρχείων (π.χ. `01-dynameis.js`).
- **Σειρά αρχείων:** Παράγε και καταχώρισε τα sections αυστηρά με αύξον `order` / `num` του κεφαλαίου.
- **Δείκτες θεμάτων:** Αν αναφέρεις «Θέμα 2ο / 4ο», γράψε `Θέμα 2<sup>ο</sup>` / `Θέμα 4<sup>ο</sup>`.
- **Γλώσσα & Ύφος:** Γράψε σε φυσικά, σύγχρονα και σαφή ελληνικά, με τεχνικούς όρους ακριβείς αλλά κατανοητούς για μαθητές ΕΠΑΛ.

- **ΑΥΣΤΗΡΗ ΕΛΛΗΝΙΚΗ ΤΡΙΓΩΝΟΜΕΤΡΙΑ (ημ, συν, εφ, σφ):**
  - Στα ελληνικά σχολικά βιβλία ΕΠΑ.Λ. απαγορεύονται ρητά οι λατινικές συντομογραφίες `\sin`, `\cos`, `\tan` ή `sin`, `cos`, `tan`.
  - Χρησιμοποιούμε **ΠΑΝΤΟΤΕ** την επίσημη ελληνική σημειογραφία:
    - Ημίτονο: `\text{ημ}\varphi` ή `\text{ημ}\theta` (στο κείμενο: `ημφ` ή `\text{ημ}\phi`)
    - Συνημίτονο: `\text{συν}\varphi` ή `\text{συν}\theta` (στο κείμενο: `συνφ` ή `\text{συν}\phi`)
    - Εφαπτομένη: `\text{εφ}\varphi` ή `\text{εφ}\theta` (στο κείμενο: `εφφ` ή `\text{εφ}\phi`)
    - Συνεφαπτομένη: `\text{σφ}\varphi` ή `\text{σφ}\theta`
  - Παράδειγμα τύπου: `\Sigma = \sqrt{F_1^2 + F_2^2 + 2 F_1 F_2 \text{συν}\varphi}`, `F_x = F \cdot \text{συν}\varphi`, `F_y = F \cdot \text{ημ}\varphi`.

- **ΕΝΣΩΜΑΤΩΣΗ ΣΧΗΜΑΤΩΝ ΚΑΙ ΔΙΑΓΡΑΜΜΑΤΩΝ ΑΠΟ ΤΟ ΒΙΒΛΙΟ:**
  - Η θεωρία δεν πρέπει να μένει μόνο σε περιγραφικό κείμενο. Όλες οι σημαντικές έννοιες (διανύσματα δυνάμεων, είδη συστημάτων δυνάμεων, κανόνας παραλληλογράμμου, δυναμοτρίγωνο, ισορροπία, ολισθαίνον διάνυσμα, δράση-αντίδραση, διαγράμματα ελευθέρου σώματος ΔΕΣ κ.λπ.) **πρέπει απαραίτητα να συνοδεύονται από τα αντίστοιχα σχήματα του σχολικού βιβλίου**.
  - Χρησιμοποίησε τα διαθέσιμα εξαγμένα σχήματα (`available_images`) μέσω block `"type": "image"`, με επεξηγηματικό `caption` (π.χ. «Σχήμα 1.2α: Το παραλληλόγραμμο των δυνάμεων») και `alt`.

## 2. ΤΕΧΝΙΚΗ ΠΡΟΔΙΑΓΡΑΦΗ JAVASCRIPT

Κάθε αρχείο πρέπει να περιέχει αυστηρά:
```javascript
window.SUBJECT_DATA = window.SUBJECT_DATA || {};
window.SUBJECT_DATA["<subject_slug>"] = window.SUBJECT_DATA["<subject_slug>"] || { sections: [], groups: [], exercises: [] };
window.SUBJECT_DATA["<subject_slug>"].sections.push({
  "slug": "<slug_name>",            // π.χ. "genika", "monades", "systima", "stoxoi"
  "num": "<chapter_num>.<seq>",     // π.χ. "1.0", "1.1", "1.2"
  "title": "<Τίτλος Ενότητας>",
  "kicker": "<Σύντομη Ετικέτα>",    // π.χ. "Βασικές Έννοιες", "Τυποποίηση", "Στόχοι"
  "lead": "<Εισαγωγική παράγραφος σύνοψης>",
  "blocks": [
    // Πίνακας με blocks
  ]
});
```

## 3. ΕΠΙΤΡΕΠΟΜΕΝΑ BLOCKS & LATEX

### Παράγραφος (`p`)
```javascript
{
  "type": "p",
  "text": "Κείμενο παραγράφου. Για μαθηματικά σύμβολα χρησιμοποίησε LaTeX inline: \\( F \\) ή $F$."
}
```

### Πλαίσιο Επισήμανσης (`callout`)
Επιτρεπόμενα kinds:
- `"def"`: Ορισμός
- `"example"`: Λυμένο Παράδειγμα (με στοίχιση ίσων από κάτω)
- `"remember"`: Θυμήσου / Βασικό σημείο
- `"tip"`: Συμβουλή / Tip Τράπεζας Θεμάτων
- `"warning"`: Προσοχή στις Εξετάσεις / Σημεία SOS

### Εικόνα (`image`)
```javascript
{
  "type": "image",
  "src": "images/b/thermo/chapter-01/theory/fig01.png",
  "caption": "Σχήμα 1.1: Διάγραμμα κατάστασης P-v.",
  "alt": "Διάγραμμα P-v"
}
```

### Μαθηματικός Τύπος (`formula`) & LaTeX
Χρησιμοποίησε LaTeX display μορφή `\\[ ... \\]` ή `$$ ... $$` μέσα στο πεδίο `html`.
Σε περιπτώσεις διαδοχικών πράξεων, χρησιμοποίησε υποχρεωτικά `aligned` με `\\\\ &=`:
```javascript
{
  "type": "formula",
  "html": "\\[ \\begin{aligned} \\sigma &= \\frac{F}{A} \\\\ &= \\frac{5000}{250} \\\\ &= 20\\text{ N/mm}^2 \\end{aligned} \\]",
  "caption": "Υπολογισμός ορθής τάσης εφελκυσμού."
}
```

### Υποκεφαλίδα (`h`), Λίστα (`ul`) & Πίνακας (`table`)
```javascript
{ "type": "h", "text": "Πολλαπλάσια και Υποπολλαπλάσια Μονάδων (Προθέματα SI)" },
{ "type": "ul", "items": ["Πρώτο βασικό σημείο.", "Δεύτερο βασικό σημείο."] },
{
  "type": "table",
  "headers": ["Πρόθεμα", "Σύμβολο", "Συντελεστής", "Τιμή"],
  "rows": [
    ["Mega", "M", "10^6", "1.000.000"],
    ["kilo", "k", "10^3", "1.000"],
    ["milli", "m", "10^-3", "0,001"]
  ]
}
```
