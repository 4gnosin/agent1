# 4gnosin.github.io - GENERATOR PROMPT: ΘΕΩΡΙΑ ΚΕΦΑΛΑΙΩΝ (window.SECTIONS)

Εργάζεσαι στο αποθετήριο του στατικού εκπαιδευτικού site **4gnosin.github.io** (GitHub Pages) με ελληνικές σημειώσεις και διαδραστικές ασκήσεις για μαθήματα Μηχανολογίας ΕΠΑ.Λ.
Στόχος είναι κάθε νέο περιεχόμενο να ταιριάζει απόλυτα και οργανικά με το υπάρχον: να είναι επιστημονικά ακριβές, διδακτικά προσεγμένο, καλαίσθητο και οργανωμένο — όχι απλώς να προσθέτει κείμενο.

## 1. ΚΑΝΟΝΕΣ ΔΟΜΗΣ ΚΕΦΑΛΑΙΟΥ
- **Παιδαγωγική Ροή:**
  1. `00-stoxoi.js`: Σαφείς επιδιωκόμενοι διδακτικοί στόχοι (`slug: "stoxoi"`, `num: "N.0"`).
  2. `01-genika.js` κ.ο.κ.: Λογικά διατεταγμένες υποενότητες (προχώρησε από το οικείο προς το νέο).
  3. Τελευταίο section: Σύντομη περίληψη / ανακεφαλαίωση (`slug: "perilipsi"`).
- **Κατάτμηση:** Κάθε υποενότητα να έχει έναν ξεκάθαρο σκοπό. Χώρισε το υλικό σε μικρές, ευανάγνωστες ενότητες· απόφυγε μεγάλες, πυκνές παραγράφους και επαναλήψεις.
- **Αρίθμηση & Ονοματοδοσία:** Διατήρησε την αρίθμηση του κεφαλαίου και τη μορφή των `num` (π.χ. `1.1`, `1.2` ή `1.2α`). Κράτησε μοναδικά `slug`, σαφείς τίτλους και περιγραφικά ονόματα αρχείων (π.χ. `01-dynameis.js`).
- **Σειρά αρχείων:** Παράγε και καταχώρισε τα sections αυστηρά με αύξον `order` / `num` του κεφαλαίου. Απαγορεύεται ανάμιξη κεφαλαίων (π.χ. αρχείο του 5ου ανάμεσα στο 2ο και το 3ο).
- **Δείκτες θεμάτων:** Αν αναφέρεις «Θέμα 2ο / 4ο», γράψε `Θέμα 2<sup>ο</sup>` / `Θέμα 4<sup>ο</sup>`.
- **Γλώσσα & Ύφος:** Γράψε σε φυσικά, σύγχρονα και σαφή ελληνικά, με τεχνικούς όρους ακριβείς αλλά κατανοητούς για μαθητές ΕΠΑΛ. Εξήγησε έναν νέο όρο πριν τον χρησιμοποιήσεις ως δεδομένο.
- **Σύνδεση με την Πράξη:** Σύνδεε τη θεωρία με πρακτικά παραδείγματα από μηχανολογικές εφαρμογές, όταν αυτό είναι κατάλληλο.

## 2. ΤΕΧΝΙΚΗ ΠΡΟΔΙΑΓΡΑΦΗ JAVASCRIPT

Κάθε αρχείο πρέπει να περιέχει αυστηρά:
```javascript
window.SECTIONS = window.SECTIONS || [];
window.SECTIONS.push({
  "slug": "<slug_name>",            // π.χ. "genika", "monades", "systima", "stoxoi"
  "num": "<chapter_num>.<seq>",     // π.χ. "1.0", "1.1", "1.2"
  "title": "<Τίτλος Ενότητας>",
  "kicker": "<Σύντομη Ετικέτα>",    // π.χ. "Βασικές Έννοιες", "Τυποποίηση", "Στόχοι"
  "lead": "<Εισαγωγική παράγραφος σύνοψης>",
  "blocks": [
    // Πίνακας με blocks
  ]
});
```

## 3. ΕΠΙΤΡΕΠΟΜΕΝΑ BLOCKS & LATEX

### Παράγραφος (`p`)
```javascript
{
  "type": "p",
  "text": "Κείμενο παραγράφου. Για μαθηματικά σύμβολα χρησιμοποίησε LaTeX inline: \\( F \\) ή $F$."
}
```

### Πλαίσιο Επισήμανσης (`callout`)
Επιτρεπόμενα kinds: `"def"` (Ορισμός), `"example"` (Παράδειγμα), `"remember"` (Θυμήσου / SOS), `"tip"` (Συμβουλή).
*Χρησιμοποίησε τα callouts με φειδώ, μόνο για ουσιώδεις επισημάνσεις.*
```javascript
{
  "type": "callout",
  "kind": "def",
  "title": "Ορισμός Κοχλία",
  "text": "Κοχλίας ονομάζεται το κυλινδρικό στέλεχος που φέρει ελικοειδή αύλακα..."
}
```

### Μαθηματικός Τύπος (`formula`) & LaTeX
Χρησιμοποίησε LaTeX display μορφή `\\[ ... \\]` ή `$$ ... $$` μέσα στο πεδίο `html`.
**ΠΡΟΣΟΧΗ ΣΤΑ ESCAPES:** Στο JavaScript string, απόδρασε σωστά τις καθέτους (`\\\\`):
```javascript
{
  "type": "formula",
  "html": "\\[ \\sigma = \\frac{F}{A_1} \\le \\sigma_{\\varepsilon\\pi} \\]",
  "caption": "Υπολογισμός τάσης εφελκυσμού κοχλία σε απλό εφελκυσμό."
}
```

### Υποκεφαλίδα (`h`), Λίστα (`ul`) & Πίνακας (`table`)
```javascript
{ "type": "h", "text": "Γεωμετρικά Χαρακτηριστικά Μετρικού Σπειρώματος" },
{ "type": "ul", "items": ["Πρώτο βασικό σημείο.", "Δεύτερο βασικό σημείο."] },
{ "type": "table", "headers": ["Κλάση", "Rm (N/mm²)", "Re (N/mm²)"], "rows": [["8.8", "800", "640"]] }
```
