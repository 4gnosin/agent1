# 4gnosin.github.io - GENERATOR PROMPT: ΑΣΚΗΣΕΙΣ & ΟΜΑΔΕΣ (JSON SCHEMA)

Εργάζεσαι στο αποθετήριο του στατικού εκπαιδευτικού site **4gnosin.github.io** (GitHub Pages) με ελληνικές σημειώσεις και διαδραστικές ασκήσεις για μαθήματα Μηχανολογίας ΕΠΑ.Λ.
Στόχος είναι η δημιουργία διαδραστικών ασκήσεων βασισμένων στην επίσημη **Τράπεζα Θεμάτων Διαβαθμισμένης Δυσκολίας του Ι.Ε.Π.** και στα σχολικά βιβλία, που καλύπτουν τη θεωρία με σαφήνεια, ακρίβεια και διδακτική αξία.

---

## 1. ΤΕΧΝΙΚΗ ΠΡΟΔΙΑΓΡΑΦΗ: ΟΜΑΔΕΣ ΥΠΟΕΝΟΤΗΤΩΝ (`groups`)

Κάθε στοιχείο του πίνακα `groups` αντιστοιχεί σε μία υποενότητα της ύλης (ΟΧΙ ανά είδος άσκησης):

```json
{
  "id": "ch02-04-psychrometry",
  "chapter": 2,
  "title": "2.4 Η αποτύπωση των θερμοδυναμικών χαρακτηριστικών",
  "blurb": "Σύντομη περιγραφή των θεμάτων της υποενότητας"
}
```

* **Κανόνας `id`:** Υποχρεωτικά `ch{Κεφάλαιο:02d}-{Υποκεφάλαιο:02d}-{slug}` (π.χ. `"ch02-04-psychrometry"`, `"ch02-10-exartimata"`, `"ch08-02-rolos-klimatistikon-monadon"`).
* **Απαγορεύονται** ομαδοποιήσεις ανά είδος (`tf`, `mc`, `calc`).

## 2. ΤΕΧΝΙΚΗ ΠΡΟΔΙΑΓΡΑΦΗ: ΑΣΚΗΣΕΙΣ (`exercises`)

Κάθε άσκηση αντιστοιχεί σε **ένα θέμα Τράπεζας** (με όλα τα υποερωτήματά του στον πίνακα `items`):

```json
{
  "id": "ch05-18622",
  "group": "ch05-02-syndeseis",
  "kind": "mc",
  "layout": "unified",
  "code": "Θέμα 2ο · #18622",
  "bankCode": "18622",
  "title": "#18622 — Θέμα 2ο (2.1–2.2)",
  "units": 9,
  "theory": "slug-theorias",
  "stem": "Εισαγωγική εκφώνηση/δεδομένα προβλήματος ΠΡΙΝ τα υποερωτήματα.",
  "givens": [
    { "label": "$F$", "value": "12000 N" },
    { "label": "$d_1$", "value": "10 mm" }
  ],
  "items": [
    // Πίνακας με τα υποερωτήματα (βλ. ενότητα 3)
  ]
}
```

* **`kind`:** Το είδος του πρώτου item (`"mc"`, `"tf"`, `"match"`, `"blank"`, `"calc"`).
* **`layout`:** Πάντα `"unified"` (όλα τα υποερωτήματα ορατά μαζί χωρίς gating).
* **`code` / `title`:** Απλό κείμενο `Θέμα 2ο` / `Θέμα 4ο` (χωρίς `<sup>` tags).
* **`stem`:** ΜΟΝΟ αν υπάρχει ουσιαστική εκφώνηση/περιγραφή πριν τα ερωτήματα. Απαγορεύεται `stem` «Θέμα 2ο» ή κενό.
* **`givens`:** Πίνακας με δεδομένα (κυρίως σε `calc`). Τα σύμβολα στο `label` μπαίνουν με LaTeX delimiters (π.χ. `"$F$"`, `"$T_{\\text{αναρ}}$"`).

## 3. ΕΠΙΤΡΕΠΟΜΕΝΑ ΕΙΔΗ ΕΡΩΤΗΜΑΤΩΝ (`items[].kind`)

### Α. Πολλαπλής Επιλογής (`mc`)
```json
{
  "kind": "mc",
  "subq": "2.1",
  "prompt": "Ποιο είναι το προφίλ γωνίας του τυποποιημένου μετρικού σπειρώματος ISO;",
  "options": [
    { "id": "a", "text": "55°" },
    { "id": "b", "text": "60°" },
    { "id": "c", "text": "90°" },
    { "id": "d", "text": "45°" }
  ],
  "answer": "b",
  "explain": "Το τυποποιημένο μετρικό σπείρωμα κατά ISO έχει γωνία προφίλ 60°. Η γωνία 55° αφορά το σπείρωμα Whitworth."
}
```

### Β. Σωστό / Λάθος (`tf`)
```json
{
  "kind": "tf",
  "subq": "2.1",
  "prompt": "Οι ηλωτές συνδέσεις (πριτσινώματα) ανήκουν στις λυόμενες συνδέσεις.",
  "answer": false,
  "explain": "Λάθος. Οι ηλώσεις είναι μόνιμες (μη λυόμενες) συνδέσεις, διότι για την αποσυναρμολόγησή τους απαιτείται καταστροφή των ήλων."
}
```

### Γ. Αντιστοίχιση (`match`)
```json
{
  "kind": "match",
  "subq": "2.1",
  "prompt": "Αντιστοιχίστε το μέσο σύνδεσης με την κατηγορία του:",
  "left": [
    { "id": "1", "text": "Κοχλίας και περικόχλιο" },
    { "id": "2", "text": "Ήλος (πριτσίνι)" }
  ],
  "right": [
    { "id": "a", "text": "Μόνιμη (μη λυόμενη) σύνδεση" },
    { "id": "b", "text": "Λυόμενη σύνδεση" }
  ],
  "pairs": {
    "1": "b",
    "2": "a"
  },
  "explain": "Ο κοχλίας προσφέρει λυόμενη σύνδεση, ενώ οι ήλοι είναι μη λυόμενες (μόνιμες) συνδέσεις."
}
```

**Κανόνας Αντιστοίχισης με Σχήμα/Διάγραμμα:**
* Όταν η Στήλη Α αναφέρεται σε σχήμα με αριθμημένα βέλη/γραμμές (1, 2, 3), το `text` είναι αυστηρά ο αριθμός/όνομα της εκφώνησης (π.χ. `"Γραμμή 1"` ή `"1"`).
* **Απαγορεύεται** να προστίθενται επεξηγήσεις σε παρενθέσεις (π.χ. `"(καμπύλη)"`), διότι προδίδουν τη λύση.

### Δ. Συμπλήρωση Κενών (`blank`)
```json
{
  "kind": "blank",
  "subq": "2.2",
  "prompt": "Συμπληρώστε τα κενά για τις κλάσεις ποιότητας κοχλιών:",
  "textBefore": [
    "Στην κλάση 8.8, το πρώτο ψηφίο δείχνει όριο θραύσης ",
    " N/mm², ενώ το δεύτερο ψηφίο δείχνει όριο διαρροής ",
    " N/mm²."
  ],
  "answers": [
    "800",
    "640"
  ],
  "bank": [
    "800",
    "640",
    "100",
    "400"
  ],
  "explain": "Όριο θραύσης: 8 &times; 100 = 800 N/mm². Όριο διαρροής: 0,8 &times; 800 = 640 N/mm²."
}
```

### Ε. Υπολογιστικό υποερώτημα (`calc`) & Μαθηματικά
```json
{
  "kind": "calc",
  "subq": "4.2",
  "prompt": "Υπολογίστε την επιτρεπόμενη δύναμη εφελκυσμού $F$ του κοχλία σε N.",
  "formula": "$F = \\sigma_{\\text{επ}} \\cdot A_1$",
  "answer": 6400,
  "unit": "N",
  "tolerance": 0.02,
  "hint": "Χρησιμοποιήστε τον τύπο $F = \\sigma_{\\text{επ}} \\cdot A_1$.",
  "explain": "Η δύναμη υπολογίζεται από: $F = 80\\text{ N/mm}^2 \\cdot 80\\text{ mm}^2 = 6400\\text{ N}$."
}
```

* **Μονάδες (`unit`):** Καθαρό σύμβολο μονάδας (π.χ. `"°C"`, `"bar"`, `"m/s"`, `"kJ/kg"`, `"N"`). Ποτέ ακατέργαστος κώδικας LaTeX όπως `"^\\circ\\text{C}"`.
* **Ανοχή (`tolerance`):** Σχετικό σφάλμα (π.χ. `0.02` = 2%).

## 4. ΚΑΝΟΝΕΣ ΠΟΙΟΤΗΤΑΣ & ΕΠΑΛΗΘΕΥΣΗΣ

1. **Υποχρεωτική Επεξήγηση (`explain`):** Κάθε ερώτημα ΠΡΕΠΕΙ να περιέχει σαφή εξήγηση για να μαθαίνει ο μαθητής από το λάθος του.
2. **Σύνδεση με Θεωρία:** Το πεδίο `"theory"` συνδέεται με υπαρκτό `slug` θεωρίας.
3. **Καθαρό JSON Output:** Επιστρέφεται αποκλειστικά έγκυρο JSON (`application/json`), χωρίς Markdown enclosures (` ```json `), χωρίς σχόλια `//` και χωρίς JavaScript κώδικα.
4. **Πιστή μετατροπή πηγής — ΚΑΜΙΑ παράλειψη:** Εντόπισε **όλες** τις εκφωνήσεις του PDF. Αν δεν γίνεται πλήρως διαδραστικό (π.χ. σχέδιο P–V), βάλε εκφώνηση + ό,τι ελέγχεται· **ποτέ μην παραλείπεις ολόκληρο θέμα**.
5. **Πηγή από PDF (σπασμένο κείμενο):** ΜΗΝ επινοείς αριθμούς, τύπους ή φυσική που δεν τεκμηριώνονται ρητά στην εκφώνηση ή στην επίσημη «ΕΝΔΕΙΚΤΙΚΗ ΑΠΑΝΤΗΣΗ».
6. **Ένα θέμα Τράπεζας = μία άσκηση:** Όλα τα υποερωτήματα (2.1, 2.2 ή α, β, γ) ανήκουν στον πίνακα `items` της ίδιας άσκησης.
7. **Ομάδες = υποενότητες:** Απαγορεύονται groups ανά είδος (`tf`, `mc`, `calc`).
8. **Δείκτες:** `Θέμα 2ο` / `Θέμα 4ο` (απλό κείμενο χωρίς `<sup>` tags).
9. **ΥΠΟΧΡΕΩΤΙΚΟ `stem` όταν υπάρχει εισαγωγικό πλαίσιο/δεδομένα:**
   Αντίγραψε πλήρως όλη την αρχική εκφώνηση και τα κοινά δεδομένα στο `"stem"`.
10. **ΑΡΙΘΜΗΣΗ ΥΠΟΕΡΩΤΗΜΑΤΩΝ (`subq` & `subqPrompt`):**
    * Κάθε item έχει πεδίο `"subq"` με τον επίσημο αριθμό του PDF (π.χ. `"2.1"`, `"2.2"`, `"4.1"` ή `"α"`, `"β"`).
    * Όταν ένα υποερώτημα έχει επιμέρους προτάσεις (π.χ. 2.1 Σωστό/Λάθος α, β, γ, δ), δώσε σε όλα το ίδιο `"subq"` και στο 1ο βάλε `"subqPrompt"`.
11. **ΕΡΩΤΗΣΕΙΣ ΑΝΑΠΤΥΞΗΣ / ΑΙΤΙΟΛΟΓΗΣΗΣ (`"openEnded": true`):**
    * Ερωτήσεις ανοιχτής απάντησης/αιτιολόγησης μετατρέπονται σε `"kind": "mc"` με `"openEnded": true`, με σωστή επιλογή την ενδεικτική απάντηση του ΙΕΠ και επιστημονικά αληθοφανείς αντιπερισπασμούς (`options` με IDs `"a"`, `"b"`, `"c"`, `"d"`).
12. **ΣΧΕΔΙΑΣΤΙΚΑ ΕΡΩΤΗΜΑΤΑ ΣΕ ΧΑΡΤΗ / ΔΙΑΓΡΑΜΜΑ (`"kind": "open"`):**
    * Καταχωρίζονται ως `"kind": "open"`, με `"prompt"` την εκφώνηση και `"explain"` τη λύση.
13. **ΤΟΠΟΘΕΤΗΣΗ ΕΙΚΟΝΩΝ (`image`, `images`, `hintImage`):**
    * Πλήρεις διαδρομές: `images/<grade>/<subject>/chapter-<NN>/<filename>.webp`.
    * Εικόνες που αφορούν συγκεκριμένο υποερώτημα μπαίνουν στο `item.image` (ή `item.images`), ΟΧΙ στο `ex.image`.
    * Σχήματα από την ενδεικτική απάντηση μπαίνουν ως `"hintImage"` στο αντίστοιχο υποερώτημα και στο `"solutionImages"` της άσκησης.
    * **ΑΠΑΓΟΡΕΥΕΤΑΙ ΑΥΣΤΗΡΑ** να βάζεις εικόνα αν δεν υπάρχει ρητό Markdown image tag (`![...](...)`) στο κείμενο του συγκεκριμένου θέματος στην πηγή. ΜΗΝ επινοείς ποτέ εικόνες εκφωνήσεων!
14. **ΣΥΜΠΛΗΡΩΣΗ ΚΕΝΩΝ (`blank`):**
    * Πολλαπλά κενά του ίδιου υποερωτήματος οργανώνονται σε **ΕΝΑ ενιαίο** `blank` item με `textBefore`, `answers` και κοινό `bank`.
15. **ΕΛΛΗΝΙΚΗ ΚΩΔΙΚΟΠΟΙΗΣΗ & ΠΙΣΤΟΤΗΤΑ:**
    * Χρησιμοποίησε αυστηρά ελληνικούς χαρακτήρες (Unicode Greek) και ποτέ κυριλλικά ομόγλυφα (όπως κυριλλικό 'К').
    * Τα `pairs` της αντιστοίχισης ακολουθούν απαρέγκλιτα το επίσημο κλειδί απαντήσεων του Ι.Ε.Π.
