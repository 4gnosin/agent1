Εργάζεσαι στο αποθετήριο του στατικού εκπαιδευτικού site **4gnosin.github.io** (GitHub Pages) με ελληνικές σημειώσεις και διαδραστικές ασκήσεις για μαθήματα Μηχανολογίας ΕΠΑ.Λ.
Στόχος είναι η δημιουργία διαδραστικών ασκήσεων βασισμένων στην επίσημη **Τράπεζα Θεμάτων Διαβαθμισμένης Δυσκολίας του Ι.Ε.Π.** και στα σχολικά βιβλία, που καλύπτουν τη θεωρία με σαφήνεια, ακρίβεια και διδακτική αξία.

## 1. ΤΕΧΝΙΚΗ ΠΡΟΔΙΑΓΡΑΦΗ: `groups.js`

```javascript
window.GROUPS = window.GROUPS || [];
window.GROUPS.push(
  {
    "id": "<subsection_slug>",   // π.χ. "ch05-first-law" — ΟΧΙ tf/mc/calc
    "chapter": "<chapter_num>",  // π.χ. "5"
    "title": "<Υποενότητα ύλης>", // π.χ. "5.1 Πρώτος Θερμοδυναμικός Νόμος"
    "blurb": "<Σύντομη περιγραφή των θεμάτων της υποενότητας>"
  }
);
```

## 2. ΤΕΧΝΙΚΗ ΠΡΟΔΙΑΓΡΑΦΗ: `window.EXERCISES`

```javascript
window.EXERCISES = window.EXERCISES || [];
window.EXERCISES.push({
  "id": "<μοναδικό_id_άσκησης>", // π.χ. "ch05-18622" — ένα θέμα Τράπεζας = μία άσκηση
  "group": "<subsection_slug>",  // ΠΡΕΠΕΙ να αντιστοιχεί σε id υποενότητας του groups.js
  "kind": "mc" | "tf" | "match" | "blank" | "calc", // είδος του πρώτου item (συμβατότητα schema)
  "layout": "unified",           // όλα τα υποερωτήματα ορατά μαζί — χωρίς gating
  "code": "Θέμα 2ο · #18622", // απλό κείμενο — το site μορφοποιεί το ο σε ανώτερο δείκτη
  "bankCode": "18622",
  "title": "#18622 — Θέμα 2ο (2.1–2.2)",
  "units": 9,                    // Μόρια άσκησης (π.χ. 9, 12, 16, 25)
  "theory": "<slug_θεωρίας>",    // Το slug της αντίστοιχης ενότητας θεωρίας
  // "stem": ΜΟΝΟ αν υπάρχει πραγματική εκφώνηση/πλαίσιο ΠΡΙΝ τα υποερωτήματα.
  // ΑΠΑΓΟΡΕΥΕΤΑΙ stem = "Θέμα 2ο" / "Θέμα 4ο" / κενό "" — αυτά καλύπτονται από code & title.
  // [Μόνο για "calc"]:
  "givens": [
    { "label": "F", "value": "12000 N" },
    { "label": "d₁", "value": "10 mm" }
  ],
  "items": [
    // Πίνακας με τα υποερωτήματα
  ]
});
```

## 3. ΕΠΙΤΡΕΠΟΜΕΝΑ ΕΙΔΗ ΑΣΚΗΣΕΩΝ (`items[].kind`)

### Α. Πολλαπλής Επιλογής (`mc`)
```javascript
{
  "kind": "mc",
  "prompt": "Ποιο είναι το προφίλ γωνίας του τυποποιημένου μετρικού σπειρώματος ISO;",
  "options": [
    { "id": "a", "text": "55°" },
    { "id": "b", "text": "60°" },
    { "id": "c", "text": "90°" },
    { "id": "d", "text": "45°" }
  ],
  "answer": "b",
  "explain": "Το τυποποιημένο μετρικό σπείρωμα κατά ISO έχει γωνία προφίλ 60°. Η γωνία 55° αφορά το σπείρωμα Whitworth."
}
```

### Β. Σωστό / Λάθος (`tf`)
```javascript
{
  "kind": "tf",
  "prompt": "Οι ηλωτές συνδέσεις (πριτσινώματα) ανήκουν στις λυόμενες συνδέσεις.",
  "answer": false,
  "explain": "Λάθος. Οι ηλώσεις είναι μόνιμες (μη λυόμενες) συνδέσεις, διότι για την αποσυναρμολόγησή τους απαιτείται καταστροφή των ήλων."
}
```

### Γ. Αντιστοίχιση (`match`)
```javascript
{
  "kind": "match",
  "prompt": "Αντιστοιχίστε το μέσο σύνδεσης με την κατηγορία του:",
  "left": [
    { "id": "1", "text": "Κοχλίας και περικόχλιο" },
    { "id": "2", "text": "Ήλος (πριτσίνι)" }
  ],
  "right": [
    { "id": "a", "text": "Μόνιμη (μη λυόμενη) σύνδεση" },
    { "id": "b", "text": "Λυόμενη σύνδεση" }
  ],
  "pairs": {
    "1": "b",
    "2": "a"
  },
  "explain": "Ο κοχλίας προσφέρει λυόμενη σύνδεση, ενώ οι ήλοι είναι μη λυόμενες (μόνιμες) συνδέσεις."
}
```

### Δ. Συμπλήρωση Κενών (`blank`)
```javascript
{
  "kind": "blank",
  "prompt": "Συμπληρώστε τα κενά για τις κλάσεις ποιότητας κοχλιών:",
  "textBefore": [
    "Στην κλάση 8.8, το πρώτο ψηφίο δείχνει όριο θραύσης ",
    " N/mm², ενώ το δεύτερο ψηφίο δείχνει όριο διαρροής ",
    " N/mm²."
  ],
  "answers": [
    "800",
    "640"
  ],
  "bank": [
    "800",
    "640",
    "100",
    "400"
  ],
  "explain": "Όριο θραύσης: 8 &times; 100 = 800 N/mm². Όριο διαρροής: 0,8 &times; 800 = 640 N/mm²."
}
```

### Ε. Υπολογιστικό υποερώτημα (`calc`) & μαθηματικά
Κάθε υπολογιστικό μέρος είναι ένα item μέσα στο ίδιο θέμα. Μην κρύβεις τα επόμενα μέρη πίσω από «βήματα».

**Σημαντικό για εμφάνιση στο site:**
- Τα πεδία `formula` και `hint` εμφανίζονται ως απλό κείμενο (χωρίς KaTeX). Γράφε εκεί **Unicode** (`·`, `Δ`, `₁`, `₂`, `−`), **όχι** raw LaTeX.
- Το πεδίο `explain` υποστηρίζει KaTeX με `\\( ... \\)`. Μόνο εκεί βάλε LaTeX.
- Τα `code` / `title`: γράφε απλά `Θέμα 4ο` (χωρίς `<sup>`). Το site προσθέτει μόνο του τον ανώτερο δείκτη.

```javascript
{
  "kind": "calc",
  "prompt": "Υπολογίστε την επιτρεπόμενη δύναμη εφελκυσμού F του κοχλία.",
  "formula": "F = σ_επ · A₁",
  "answer": 6400,
  "unit": "N",
  "tolerance": 0.02,
  "hint": "Χρησιμοποιήστε τον τύπο F = σ_επ · A₁.",
  "explain": "Η δύναμη υπολογίζεται από: \\( F = 80\\text{ N/mm}^2 \\cdot 80\\text{ mm}^2 = 6400\\text{ N} \\)."
}
```

## 4. ΚΑΝΟΝΕΣ ΠΟΙΟΤΗΤΑΣ & ΕΠΑΛΗΘΕΥΣΗΣ
1. **Υποχρεωτική Επεξήγηση (`explain`):** Κάθε ερώτημα ΠΡΕΠΕΙ να περιέχει σαφή εξήγηση για να μαθαίνει ο μαθητής από το λάθος του.
2. **Σύνδεση με Θεωρία:** Το πεδίο `"theory"` πρέπει να συνδέεται με υπαρκτό `slug` θεωρίας.
3. **Escapes:** Στο JavaScript string, τα backslashes του LaTeX (μόνο στο `explain`) πρέπει να είναι διπλά (`\\\\sigma`, `\\\\text`).
4. **Πιστή μετατροπή πηγής — ΚΑΜΙΑ παράλειψη:** Εντόπισε **όλες** τις εκφωνήσεις. Αν δεν γίνεται πλήρως διαδραστικό (π.χ. σχέδιο P–V), βάλε εκφώνηση + ό,τι ελέγχεται· **ποτέ μην παραλείπεις ολόκληρο θέμα**.
5. **Πηγή από PDF (σπασμένο κείμενο):** Το MD μπορεί να έχει artifacts εξαγωγής. **Απαγορεύεται** να επινοείς αριθμούς, τύπους ή φυσική που δεν τεκμηριώνονται στην εκφώνηση ή στην «ΕΝΔΕΙΚΤΙΚΕΣ ΑΠΑΝΤΗΣΕΙΣ». Για `calc`, το `answer` βγαίνει **μόνο** από ρητούς αριθμούς της λύσης/εκφώνησης. Αν η λύση είναι ασαφής, προτίμησε mc/tf με βάση το κείμενο της λύσης αντί να μαντέψεις αποτέλεσμα.
6. **Καθαρή εξαγωγή:** Μόνο έγκυρο JSON/JS χωρίς backticks.
7. **Ένα θέμα Τράπεζας = μία άσκηση:** Μέρη 2.1/2.2 ή α/β/γ στο ίδιο αντικείμενο.
8. **Ομάδες = υποενότητες:** Απαγορεύονται groups με id `tf`, `mc`, `match`, `blank`, `calc`.
9. **Δείκτες:** `Θέμα 2ο` / `Θέμα 4ο` (απλό κείμενο). **Απαγορεύεται** το `<sup>ο</sup>` στα strings.
10. **`stem` — χωρίς επανάληψη θέματος:** Μην βάζεις στο `stem` μόνο «Θέμα Xο» / «Θέμα Xᵒ» / κενό `""`. Το θέμα φαίνεται ήδη σε `code` και `title`. Το `stem` υπάρχει **μόνο** όταν υπάρχει ουσιαστική εκφώνηση ή δεδομένα πριν τα υποερωτήματα· αλλιώς **παράλειψε εντελώς** το πεδίο `stem`.
